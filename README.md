# PSMacc — โปรแกรมบัญชีออนไลน์สำหรับธุรกิจไทย

เว็บแอปบัญชีแบบไฟล์เดียว (HTML + JavaScript ล้วน ไม่ต้องมีเซิร์ฟเวอร์)

## ความสามารถหลัก
- เอกสารขาย/ซื้อ: ใบเสนอราคา ใบสั่งขาย ใบแจ้งหนี้ ใบเสร็จ ใบลดหนี้ ใบวางบิล บิลซื้อ ค่าใช้จ่าย เช็คจ่าย
- ลงบัญชีคู่อัตโนมัติ สมุดรายวัน แยกประเภท งบทดลอง งบกำไรขาดทุน งบดุล และรายงานมาตรฐาน 80+ รายงาน
- ภาษี: ภ.พ.30 (VAT รอเรียกเก็บสำหรับค่าบริการ), หัก ณ ที่จ่าย, หนังสือรับรอง 50 ทวิ
- ธนาคาร: บัญชีหลายบัญชี, กระทบยอด, นำเข้า Statement (CSV/Excel/PDF) และจับคู่อัตโนมัติ
- ปิดงบรายเดือน, ยอดยกมาจากงบปีก่อน, หลายบริษัท/หลายสาขา, โครงการ/แผนก
- พิมพ์/PDF ฟอร์มเอกสาร (ต้นฉบับ/สำเนา), แนบไฟล์, อ่านใบเสร็จด้วย OCR (Tesseract)
- นำเข้า/ส่งออกข้อมูล Excel

## โครงสร้าง
```
src/shell.html     CSS + โครง HTML
src/part02.js      ข้อมูลหลัก ฟอร์มเอกสาร การรับ/จ่ายชำระ การลงบัญชี
src/part03.js      หน้าเมนูต่าง ๆ
src/part04.js      รายงาน
src/part05.js      ตั้งค่า / ข้อมูลบริษัท
src/part06.js      รูปแบบฟอร์มเอกสาร
src/part07.js      นำเข้า/ส่งออกข้อมูล
src/part08.js      ธุรกรรมธนาคาร
src/part09.js      บันทึกหลายรายการ
src/part10.js      กระทบยอด
src/part11.js      ปิดงบรายเดือน
src/part12.js      นำเข้า Statement ธนาคาร
src/part13.js      พิมพ์ / PDF
src/part14.js      50 ทวิ
src/part15.js      หลายบริษัท / สาขา
src/part16.js      โครงการ / แผนก
src/part17.js      อ่านเอกสาร OCR
src/part18.js      ยอดยกมา
dist/index.html    ไฟล์เว็บที่ประกอบแล้ว (เปิดในเบราว์เซอร์ได้เลย)
dist/artifact.html สำหรับเผยแพร่เป็น Claude Artifact
tests/             สคริปต์ทดสอบ Playwright
```

## วิธีใช้
1. แก้ไฟล์ใน `src/` แล้วรัน `./build.sh`
2. เปิด `dist/index.html` หรือ `index.html` ในเบราว์เซอร์

### เผยแพร่บน GitHub Pages
Settings → Pages → Source: `main` branch, โฟลเดอร์ `/ (root)` → เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## การเก็บข้อมูล
- เปิดเป็น **Claude Artifact**: ข้อมูลเก็บในฐานข้อมูลของ Artifact ใช้ร่วมกันได้หลายคน
- เปิดเป็น **ไฟล์/GitHub Pages**: ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น
  ควรสำรองข้อมูลสม่ำเสมอ (ฟันเฟือง → สำรองข้อมูลบริษัท) และฟีเจอร์แนบไฟล์/อ่านเอกสารด้วย Claude ใช้ไม่ได้ในโหมดนี้

## ทดสอบ
```
npm i -g playwright
NODE_PATH=$(npm root -g) node tests/t65.js
```
(สคริปต์ทดสอบอ้างอิงไฟล์ `t_view.html` ให้สร้างด้วย `cp dist/index.html tests/t_view.html`)
